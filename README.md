# Spokillion · the daily climb

A daily cycling trivia game inspired by Krillion. Each prompt (Tour winners, climbs, bike parts, jargon…) wants one correct answer, and rarer answers score more and climb you higher up the mountain.

- Daily stage of 7 prompts (same for everyone on a given date) plus unlimited mode
- Six rarity tiers, from Peloton (10 pts) to One in a Spokillion (130 pts)
- Rarity tiers are editorial guesses, not live player stats
- Streaks and best altitude are saved in your browser's localStorage

Plain HTML/CSS/JS with no build step. Run locally with `python3 -m http.server` and open http://localhost:8000. Pushes to `main` deploy to GitHub Pages.
